# ملفات مصدر موقع مطبخي

هذا أرشيف مصدر الموقع المستخرج من مرفقات المهمة. يتضمن React/Vite وExpress/tRPC وDrizzle migrations وtests وأصولًا. `.env.example` منقح إلى أسماء متغيرات فقط. لا يحتوي قاعدة بيانات فعلية أو مجلد build/ الكامل أو أسرارًا/كلمات مرور. راجع README_AR.md في الحزمة الجامعة لملاحظات تغطية البيانات والـ HTML.
