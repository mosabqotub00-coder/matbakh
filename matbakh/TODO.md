- [ ] إنشاء دور مستقل باسم المطوّر بصلاحيات كاملة على جميع الفروع والحسابات والمراقبة، مع عدم منحه نطاق فرع موظف عادي.
- [ ] إضافة مركز أخطاء تقني منفصل يسجل تجمّد العمليات وفشل الطلبات والاتصال والتنبيهات مع الفرع والحساب والوقت والحالة، دون تسجيل كلمات المرور أو أسرار الجلسات.
- [ ] إضافة مركز ملاحظات للموظفين والمديرين يتيح وصف المشكلة وربطها بالطلب وإرفاق صورة أو تسجيل صوتي عند توفره، مع توجيهها حسب الصلاحية.
- [ ] إضافة إعدادات تنبيهات أساسية، بحيث يبقى تنبيه انتهاء الوقت الأصلي لموظفي المطبخ ومدير المطبخ فقط، ويبدأ التصعيد الرسمي بعد نهاية السماح، ويبقى صوت مدير الفروع مغلقًا افتراضيًا.
- [ ] إضافة سجل إصدارات ومسودات تحديث ومفاتيح تفعيل يمكن أن تستهدف المطوّر أو فرعًا محددًا أو جميع الفروع، مع إبقاء الفروع على نسختها الحالية أثناء تجربة المطوّر.
- [ ] إضافة فحص آلي أولي للإصدار التجريبي والتحقق من الصلاحيات والمسارات والبناء، مع إبقاء رفع ZIP وتشغيل الكود المرفوع معزولًا وعدم تنفيذ ملفات غير موثوقة على الإنتاج.
- [ ] تأجيل التقارير اليومية والأسبوعية والشهرية والتحليلات المتقدمة خارج هذه المرحلة وتأجيلها.
- [ ] إضافة أصناف سريعة مثل ظرف ملفوف وظرف ثومة وظرف شطة وعلب الصوص والصوص الملكي والسويت، بحيث تظهر للمطبخ كتذاكر عادية بلا مؤقت أو تنبيه تأخير.
